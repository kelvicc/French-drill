## 📦 【完全オフライン版】ZIPパッケージのダウンロード

電波の届かない機内、地下鉄、海外渡航先など、完全オフライン環境で音声を100%再生したい場合は、以下の同梱ZIPファイルをダウンロードして端末で解凍してご利用ください。

- **[📥 french_speaking_drill_neural_complete.zip](./french_speaking_drill_neural_complete.zip)**（約 41.6 MB / 全 3,774 音声ファイル同梱）

### オフライン版の使い方
1. 上記の `french_speaking_drill_neural_complete.zip` をダウンロードします。
2. 任意のフォルダに解凍（展開）します。
   - **iPhone**: 標準「ファイル」アプリでタップするだけで自動展開されます（または「Documents by Readdle」アプリ等）。
   - **Android**: 標準「Files」アプリ等で解凍します。
   - **PC / Mac**: ダブルクリック等で解凍します。
3. 展開されたフォルダ内の **`index.html`** をブラウザで開きます。
4. インターネット接続が一切ない状態でも、すべてのネイティブ音声（3,774ファイル）が即座に再生されます。

## 📚 収録カリキュラム（全8部・全55パターン）

### 1. 全55パターン・スピーキング自動化ドリル（全1,650問）
- **ドリルA（スロット置換・骨格無意識化）**: 550問（主語・動詞・目的語を反射置換）
- **ドリルB（構文変形・スイッチ対話）**: 550問（Henri男声 ➔ Denise女声のリアル対話スイッチ）
- **ドリルC（状況対応・瞬発発話フラッシュカード）**: 550問（0.5秒で口から出す瞬発ドリル）
- **各パターン基本モデル文**: 55パターン（SVG図解カード付き）

### 2. 🔥 最重要動詞 活用辞書（6大時制スワイプ表）＆ 瞬発クイズ
- **網羅する6大時制**: 現在形 (`Présent`)、複合過去 (`Passé Composé`)、半過去 (`Imparfait`)、単純未来 (`Futur Simple`)、条件法現在 (`Conditionnel Présent`)、接続法現在 (`Subjonctif Présent`: `Que je ... / Qu'il ...`)
- **38大コア動詞（辞書機能）**: 最重要不規則動詞22語 ＋ 初見でつづりを間違えやすい重要第1群 `-er` 動詞14語（`acheter`, `préférer`, `espérer`, `appeler`, `jeter`, `envoyer`, `payer`, `essayer`, `étudier`, `créer`, `manger`, `commencer`, `parler`, `aimer`）＋ 第2群 `-ir` 代表モデル2語
- **62語の規則・綴り変化動詞バンク拡大クイズ**: 日常頻出の規則・語幹変化動詞を含む全100動詞フラッシュカード
