## 📚 収録カリキュラム

### 1. 全50パターン・スピーキング自動化ドリル（全1,500問）
- **ドリルA（スロット置換・骨格無意識化）**: 500問（主語・動詞・目的語を反射置換）
- **ドリルB（構文変形・スイッチ対話）**: 500問（Henri男声 ➔ Denise女声のリアル対話スイッチ）
- **ドリルC（状況対応・瞬発発話フラッシュカード）**: 500問（0.5秒で口から出す瞬発ドリル）
- **各パターン基本モデル文**: 50文（SVG図解カード付き）

### 2. 🔥【新機能】最重要動詞 活用辞書（5大時制スワイプ表）＆ 瞬発クイズ
- **網羅する5大時制**:
  1. **現在形 (Présent)**: 発話の基本エンジン
  2. **複合過去 (Passé Composé)**: avoir/être ＋ 過去分詞（完了・点）
  3. **半過去 (Imparfait)**: nous語幹 ＋ -ais, -ions（描写・継続・線・背景）
  4. **単純未来 (Futur Simple)**: 未来語幹 ＋ -ai, -as, -a, -ons...（将来の確定事項）
  5. **条件法現在 (Conditionnel Présent)**: 未来語幹 ＋ 半過去語尾（丁寧・願望・仮定）
- **28大コア動詞（辞書機能）**:
  - **最重要不規則動詞（22動詞）**: être, avoir, aller, faire, vouloir, pouvoir, devoir, savoir, venir, prendre, mettre, dire, voir, falloir, partir, sortir, comprendre, attendre, entendre, lire, écrire, vivre
  - **第1群・第2群 代表モデル（6動詞）**: parler, aimer, habiter, commencer, finir, choisir
- **時制スワイプ機能**: 動詞カード上を左右にスワイプ（または上部ピルタップ）することで、5つの時制の活用表が滑らかに切り替わります。
- **インクリメンタル検索**: 不定詞名（aller, voir等）や日本語（行く、見る等）で即座に絞り込み可能。
- **52語の規則動詞バンク拡大クイズ**: 代表動詞28語に加え、日常頻出の規則動詞（écouter, chercher, penser, regarder, etc.）も出題プールに動的生成され、活用パターンの応用力を定着させます。
