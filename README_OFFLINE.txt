「話すため」のフランス語文 全パターンドリル (Neural AI Edition / Approach B)
完全オフライン再生パッケージ（PC・タブレット版 ＆ スマホ最適化版 同梱）
========================================================================

■ 概要
マイクロソフト Azure 高精度ニューラルAI音声（Henri 男性声 / Denise 女性声）で
収録された全50パターン（1,500ドリル問題＋基本モデル文）および、
【最重要動詞 活用辞書（5大時制スワイプ表）＆ 瞬発クイズ】（28大動詞・5大時制・840音声 ＋ 52語彙拡大バンク）の
完全オフライン学習教材です。
インターネット接続が一切ない環境（地下鉄、機内、電波の届かない場所など）でも
高音質かつ男女の自然なイントネーションで再生・学習できます。

■ 収録内容
1. 【全50パターン・スピーキング自動化ドリル】
   - ドリルA（スロット置換・骨格無意識化）: 500問
   - ドリルB（構文変形・スイッチ対話）: 500問（男女リアル対話形式）
   - ドリルC（瞬発発話フラッシュカード）: 500問（0.5秒反射ドリル）
   - 各パターン基本モデル文: 50文

2. 【🔥 最重要動詞 活用辞書 ＆ 5大時制瞬発クイズ】
   - 5大時制網羅: 現在形、複合過去、半過去、単純未来、条件法現在
   - 28大コア動詞: 最重要不規則動詞22語 ＋ -er/-ir代表モデル6語
   - スワイプ式時制カルーセル（左右スワイプまたは時制ピルでスムーズ切り替え）
   - 動詞名・日本語意味によるリアルタイムインクリメンタル検索
   - 単数・複数対応表、過去分詞、助動詞（avoir/être）、発音記号(IPA)、音の急所解説
   - 840活用形のネイティブ音声完備
   - 52語の規則動詞バンクを含む全時制フラッシュカード瞬発クイズ

■ 用途に合わせた2つのHTMLプレイヤー（※本パッケージは index.html と index2.html のみで構成）
1. 【スマホで学習する場合（推奨）】
   →「index.html」
   ・1パターン集中モード（左右スワイプや次へボタンで1画面ずつ集中学習）
   ・「🔥 動詞特訓」カードへのワンタップ移動＆P一覧ドロワー
   ・親指タップに最適化した大きなタッチボタン（48px+）
   ・ドリルBに「👨 男声」「👩 女声」「👥 対話」「🐢 ゆっくり」ボタン完備
   ・ドリルCのフラッシュカード式（ワンタップで正解・音声表示）
   ・画面下部の常駐ミニプレイヤー（速度切替・停止）

2. 【PCやiPad・大画面で学習する場合】
   →「index2.html」
   ・左側サイドバー目次付きのワイドレイアウト（動詞特訓へワンクリック移動）
   ・10問連続自動再生（シャドーイングモード）
   ・再生速度切り替え（0.75x / 1.0x / 1.25x）

■ 使い方
1. 本ZIPファイルを任意のフォルダに解凍（展開）してください。
2. 上記のお好みのHTMLファイル（スマホは index.html、PCは index2.html）をブラウザ（Safari, Chrome, Edge等）で開きます。
3. ネット接続なしですぐにネイティブ音声が再生されます。

■ ファイル構成
- index.html               : スマホ最適化プレイヤー（メイン入口）

- sw.js, manifest.json    : PWAオフライン動作用ファイル
- audio/                  : ニューラルAI音声 MP3ファイル群 (約2,970ファイル)
  - audio/*.mp3           : パターンドリル音声 (1,979ファイル)
  - audio/verbs/*.mp3     : 重要動詞 5大時制活用音声 (991ファイル)
- README_OFFLINE.txt     : 本説明書
